# Security policy

## Supported versions

Until the first release, security fixes are made on the `main` branch. After
v0.1.0, only the latest released minor version is supported.

## Reporting a vulnerability

Report potential vulnerabilities privately to the package maintainer at
zyf0717@gmail.com. Include a minimal reproduction, affected version, and any
relevant impact assessment. Do not open a public issue before a coordinated
disclosure plan is agreed.
